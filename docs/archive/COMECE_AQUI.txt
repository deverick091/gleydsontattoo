### 1️⃣ Inicializar Git (5 min)

**Windows - Execute no PowerShell:**
```powershell
cd C:\Users\erick\OneDrive\Documentos\gleydsontattoo
.\setup-git.bat
```

**Mac/Linux - Execute no Terminal:**
```bash
cd ~/Documents/gleydsontattoo  # (ou caminho real)
bash setup-git.sh
```

**Resultado:** Git iniciado, arquivos adicionados, commit feito ✅

---

### 2️⃣ Criar Repositório GitHub (5 min)

1. Acesse: https://github.com/new
2. Preencha:
   - **Repository name:** `gleydsontattoo`
   - **Description:** "Sistema digital para estúdio de tatuagem"
   - **Visibility:** Public ou Private
3. Clique "Create repository"
4. Copie a URL (HTTPS)

---

### 3️⃣ Fazer Push para GitHub (2 min)

```bash
# Copie e cole no seu terminal:
git remote add origin https://github.com/SEU_USUARIO/gleydsontattoo.git
git branch -M main
git push -u origin main
```

**Resultado:** Código no GitHub ✅

---

### 4️⃣ Setup Supabase (15 min)

**Abra:** https://supabase.com/dashboard

1. "New project"
2. Nome: `gleydsontattoo`
3. Password: Senha forte (copie!)
4. Region: South America - São Paulo
5. Aguarde criação (2-3 min)

**Depois:**
```bash
# No terminal, vá para backend
cd backend

# Obtenha a URL do Supabase e coloque em .env
# DATABASE_URL=postgresql://...

# Execute as migrations
npx prisma migrate deploy
npx prisma db seed
```

**Resultado:** Database em produção ✅

---

### 5️⃣ Deploy Frontend - Vercel (10 min)

**Acesse:** https://vercel.com/new

1. "Import Git Repository"
2. Busque `gleydsontattoo`
3. Clique "Import"
4. Aguarde build automático

**Resultado:** Frontend em produção ✅
URL: `https://gleydsontattoo-*.vercel.app`

---

### 6️⃣ Deploy Backend (15 min)

**Opção A - Railway (RECOMENDADO):**
1. https://railway.app/dashboard
2. "New Project" → "Deploy from GitHub"
3. Selecione `gleydsontattoo`
4. Coloque variáveis de `.env.production.example`
5. Deploy automático

**Opção B - Vercel:**
- Mesmo processo, selecione `backend` como root

**Resultado:** Backend em produção ✅

---

### 7️⃣ Testar Tudo (10 min)

```bash
# Acesse no navegador:
https://seu-frontend.vercel.app

curl https://seu-backend.herokuapp.com/health
```
